PANDUAN PENGGUNAAN PAKET KONTEN PID — FUNDAMENTAL BASIS DATA RELASIONAL
======================================================================

1. CARA MENJALANKAN DI PID / LAPTOP (100% OFFLINE)
   - Ekstrak file ZIP ini ke dalam satu folder.
   - Buka file `index.html` menggunakan browser (Chrome, Edge, Firefox, atau browser bawaan PID).
   - Klik tombol "Layar Penuh" di pojok kanan atas (atau tekan tombol F di keyboard) untuk tampilan penuh di layar PID.

2. STRUKTUR BERKAS
   - index.html                        : Aplikasi web interaktif utama (9 halaman 16:9 tanpa scroll untuk PID + mobile-friendly)
   - PERANGKAT-AJAR-CP-TP.md           : Dokumen terpisah berisi CP, TP, Pengalaman Pembelajaran, dan KKTP untuk guru
   - assets/gambar-1-manual-vs-db.svg  : Ilustrasi perbandingan catatan manual vs basis data digital
   - assets/gambar-2-anatomi-tabel.svg : Diagram hirarki Database -> Tabel -> Kolom -> Baris
   - assets/gambar-3-relasi-erd.svg    : Diagram relasi 1-to-Many (PK -> FK) tabel kategori & barang
   - assets/og-preview.png             : Kartu pratinjau Open Graph (1200x630) untuk share media sosial / WhatsApp

3. FITUR AKSESIBILITAS & PID (TOMBOL MELAYANG POJOK KIRI BAWAH)
   - Klik tombol ikon aksesibilitas (ikon orang) di pojok kiri bawah untuk membuka panel:
     • Skala Font (A- / A+): 85% hingga 135% agar terbaca jelas hingga bangku belakang.
     • Mode Tampilan: Cerah (Daylight Neo-Brutalist), Gelap (Dark), dan Kontras Tinggi (WCAG AAA).
     • Spasi Baca: Memperlebar spasi huruf dan baris (ramah disleksia).
     • Bacakan Layar: Text-to-Speech Bahasa Indonesia bawaan browser.
     • Efek Suara (SFX): Web Audio API 100% offline dengan tombol On/Off.
   - Layar Penuh (Fullscreen) di pojok kanan atas (shortcut F) + dukungan sentuh (Drag & Drop sekaligus Tap-to-Place).
